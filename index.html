Solution

How to Fix CORS on GitHub Pages (100% Free)

GitHub Pages par browser direct private API ko block karta hai. Isko theek karne ke liye 2-minute me ek free Cloudflare Worker backend banayein:

1

Cloudflare Worker Create Karein (Free)

workers.cloudflare.com par free sign in karein aur Create Application → Create Worker par click karein.

2

Worker Code Paste Karein

Worker editor me default code hata kar niche diya gaya proxy code paste karein aur Deploy click karein:

export default {
  async fetch(req) {
    const cors = {
      "Access-Control-Allow-Origin": "*",
      "Access-Control-Allow-Methods": "POST, OPTIONS",
      "Access-Control-Allow-Headers": "Content-Type",
    };
    if (req.method === "OPTIONS") return new Response(null, { headers: cors });
    if (req.method !== "POST") return new Response("POST only", { status: 405 });
    const { aadhaar } = await req.json();
    const res = await fetch("https://mpan.in/api/pan.php", {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({
        api_key: "5b3bb13a8a1d0b11a1d1655dfd4fb65f55b6bd8b",
        aadhaar: aadhaar
      })
    });
    const data = await res.text();
    return new Response(data, {
      status: res.status,
      headers: { ...cors, "Content-Type": "application/json" }
    });
  }
};
3

Worker URL Ko Yaha Settings Me Dalein

Deploy hone ke baad aapko ek link milegi (jaise https://pan-proxy.username.workers.dev). Is website ke API Settings me jakar wo link dalein aur Save karein. Fir search 100% chalega!

Note on MPAN Phase 2B: Aapke MPAN portal par likha tha: "The public REST endpoint will be exposed in Phase 2B." Agar MPAN ke server se abhi endpoint band hai toh Worker lagane ke baad MPAN ka official error response aayega.
